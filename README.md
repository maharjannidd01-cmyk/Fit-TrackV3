# FitTrack Pro v11 — Phase 7

FitTrack Pro is an offline-first fitness PWA for workout tracking, nutrition logging, hydration and progress analytics.

## Included
- `index.html` — PWA shell
- `styles.css` — app design system and Phase 7 stabilization layer
- `app.js` — application logic
- `sw.js` — v11 service worker
- `manifest.json` — PWA metadata
- `FitTrack-Pro-v11-Preview.html` — standalone visual preview with sample data
- `AUDIT_REPORT_V11.md` — audit and fixes
- `WEARABLE_CONNECTION_GUIDE.md` — connection methods and limitations
- `PHASE_7_NOTES.md` — phase implementation notes
- `CHANGELOG_V11.md` — version history

## Wearable access
The Wearable & Health controls are available directly from Home and Settings.

Direct Web Bluetooth is intentionally labeled experimental. Full Android health-data ingestion is designed around a future Android Health Connect companion/TWA bridge.
